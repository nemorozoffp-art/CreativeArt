# CreativeArt — GitHub Pages

Загрузите содержимое этой папки в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → / (root). Сборка и backend не нужны. Пути относительные, сайт работает и в /repository/.

## Аудио
Реальные загруженные файлы: assets/audio/neon-revolt.mp3 и neon-revolt-v2.mp3. Они НЕ переименованы в демонстрационные треки. Не подтверждено, что они соответствуют запрошенным композициям.

Добавьте отсутствующие исходники:
- assets/audio/creative-pulse.mp3
- assets/audio/neural-steppe.mp3
- assets/audio/digital-rebellion.mp3
- assets/audio/beyond-the-code.mp3

Плейлист расположен в assets/app.js. Обложки — локальные SVG-шаблоны, а не ранее утвержденные картинки: в доступной истории нет подтвержденного соответствия изображений трекам. Их можно заменить в поле cover или изменить src. Оригиналы трех изображений приложены отдельно в references без назначения.

Фон не запускается автоматически, при воспроизведении трека выключается. Волны и кристалл получают частоты реального звука через Web Audio. При отсутствии файла нет синтезированной замены. Бриф скачивается локально и не отправляется. Внешних страниц разделов нет: ссылки ведут к соответствующим блокам сохраненной главной страницы.

## Проверка
Для локального просмотра используйте HTTP-сервер. Проверьте MP3, паузу, перемотку, выбор трека, ru/kk/en, клавиатуру, мобильное меню, скачивание брифа и настройки reduced motion.
Казахский перевод подготовлен для проверки носителем, как согласовано ранее.

## Внешние зависимости
Исходные Tailwind CDN, Three.js r128, Lucide и Google Fonts сохранены. Для отображения дизайна и 3D нужен доступ к CDN; аудио и обложки хранятся локально. WebGL и Web Audio зависят от браузера. Это статический пакет, не заявление о завершенной публикации.
